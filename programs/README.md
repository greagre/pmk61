# Программы из журналов и книг

Здесь лежат программы для МК-61 и нашего расширения, найденные в печатных источниках
(«Наука и жизнь», книги по программируемым микрокалькуляторам, методички).
Каждая программа хранится **текстом**, чтобы её можно было проверить на эмуляторе,
не открывая скан.

## Зачем это нужно

В журналах программа печатается в виде, который не всегда совпадает с тем, что
понимает наш эмулятор: другой порядок разрядов, другие обозначения, иногда опечатка
в самом журнале. Если такую программу не сохранить текстом, через месяц уже не
вспомнить, что именно не сошлось.

Отдельная польза — **проверка расхождений с оригиналом**. Программа из журнала
написана под настоящий МК-61. Если в эмуляторе она даёт другой результат, значит
эмулятор где-то расходится с железом, и это надо разбирать, а не подгонять программу.

## Имя файла

```
NN-nazvanie.md      например: 01-nauka-i-zhizn-perehod.md
```

Номер сквозной, чтобы файлы сортировались в порядке появления.

## Формат карточки

Каждый файл начинается с шапки:

```markdown
# Название программы

| Поле | Значение |
|:---|:---|
| Источник | журнал «Наука и жизнь», 1986, № 4, стр. 62 |
| Автор | нет данных |
| Модель | МК-61 |
| Назначение | что считает |
| Вход | что вводит пользователь |
| Выход | что должно получиться |
```

Дальше — **три формы записи одной и той же программы**, если они известны:

1. **Нажатия** — как напечатано в журнале, с пометкой спорных мест.
2. **Ассемблер** — текст для поля в панели сборки (`asm-editor.js`).
3. **Коды** — пары hex, как их показывает журнал памяти.

Затем обязательный блок:

```markdown
## Проверка

| Что | Значение |
|:---|:---|
| Ожидание по источнику | |
| Результат в эмуляторе МК-61 | |
| Результат в расширенном режиме | |
| Статус | работает / не работает / проверено частично |
```

## Правила записи

- **Ничего не дорисовывать.** Неразборчивое место помечается `[неразборчиво]`,
  сомнительное — `[?]` с пояснением, что именно смущает.
- Адреса переходов писать полностью, включая дальние: `-0` … `-4`
  (в кодах это первый байт `0A` плюс вторая цифра).
- Если журнал и эмулятор расходятся — писать оба значения, а не подгонять одно под другое.
- Если программа не заработала, в карточке указывается **где именно** сломалось:
  на каком шаге, какой адрес, какое значение в `X` вместо ожидаемого.

## Связанные файлы

- `asm61.js` — сборка текста в коды (переходы всегда 3 ячейки: код, десятки, единицы).
- `disasm61.js` — обратный разбор: коды в текст.
- `codes-panel.js` — ввод программы кодами или нажатиями.
- `codes-aliases.js` — словарь вариантов записи команд (`ИП`, `П→X`, `X#0` и другие).
