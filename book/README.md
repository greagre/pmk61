# Электроника МК-61 — книга об эмуляторе

Здесь собираются главы книги. Каждая глава — отдельный файл, оглавление ниже.

Книга про **наш** эмулятор: где поведение расходится с настоящим МК-61, это помечается отдельно.

## Для кого и как пишем

- Книга для **школьников**: всё объясняется подробно, без пропущенных шагов.
- Каждая глава — **до 30 000 знаков**, с пояснениями, аналогиями и заданиями.
- Все программы — в ассемблерном формате (вставляются в редактор эмулятора) и с таблицей: **адрес / запись в ассемблере / код / что делает**.
- ⚠️ — место, где эмулятор расходится с настоящим МК-61.
