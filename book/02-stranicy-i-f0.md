# Глава 02. Страницы программы и команда F0

## Зачем нужны страницы

У МК-61 на одной странице **105 адресов** — от 00 до 104. Программа длиннее не влезает: счётчику некуда двигаться дальше.

В нашем эмуляторе память расширена до **420 шагов** — это ровно **4 страницы по 105 адресов**. Страницы переключаются отдельной командой `F0`.

> ⚠️ **Расхождение с оригиналом.** В настоящем МК-61 страниц нет и команды `F0` не существует. Расширенная память и переходы между страницами — добавление эмулятора.

## Команды перехода

`F0` набирается как обычная команда, после неё идут две цифры.

| Команда | Куда переходит |
|:---|:---|
| `F0 20` | страница 0 |
| `F0 21` | страница 1 |
| `F0 22` | страница 2 |
| `F0 23` | страница 3 |

После перехода счётчик встаёт на **адрес 00** новой страницы.

## Чего F0 не заменяет

Косвенный переход `К БП n` страницу **не меняет и не может**: адрес в регистре всегда лежит в диапазоне 0…104, то есть внутри одной страницы. Ассемблер это проверяет — попытка перейти на метку с другой страницы даёт ошибку сборки с подсказкой «используй F0 2n».

| Команда | Что меняет |
|:---|:---|
| `К БП n` | адрес **внутри** страницы (с модификацией по регистру) |
| `F0 2n` | **номер страницы** |

## Проверенный пример

На нулевой странице — команда перехода, на первой — результат.

```asm
.page 0
F0 21
9
С/П
.page 1
7
С/П
```

| Страница | Адрес | Запись в ассемблере | Код | Что делает |
|:---:|:---:|:---|:---:|:---|
| 0 | 00 | `F0 21` | — | переключает на страницу 1, адрес 00 |
| 0 | 01 | `9` | 09 | сюда попадём, только если перехода не было |
| 0 | 02 | `С/П` | 50 | останов |
| 1 | 00 | `7` | 07 | X = 7 |
| 1 | 01 | `С/П` | 50 | останов |

**Ожидается: `7`, адрес `01`.**
Если бы `F0 21` не сработал, выполнилась бы девятка и на экране было бы `9` — результат однозначен.

## Что показывает журнал

При прогоне этой программы журнал выдаёт три шага и отдельную строку перехода:

```
#1  00  страница 1
#2  00  7        X 0 → 7, → 01
#3  01  С/П · С/П

Переходы банков и страниц:
#0  страница 0 → 1   адр 00
```

Строка перехода — самая полезная: она прямо говорит, что страница сменилась и счётчик обнулился. Если такой строки нет, значит `F0` не выполнился.

Проверено на телефоне 28.11.2026: результат `7`, адрес `01`, в журнале одна строка перехода.

## Где смотреть страницу

| Место | Как показано |
|:---|:---|
| Строка состояния | `шаг 3 · РС 01 / 105 · страница 1/4` |
| Листинг расширения | `занято 2 из 105 · банк 0 · страница 1 · адресат 0` |
| Журнал | `страница 0 → 1` |

Нумерация везде идёт **с нуля**: страница 1 — это вторая из четырёх.
