# pmk61 — архив этапа v1

Зафиксированное состояние корпуса МК-61 на 24 ноября 2026 года.
Рабочие файлы продолжают жить в корне репозитория, эта папка — снимок.

## Что в этом этапе работает

| Проверка | Результат |
|:---|:---|
| Корпус с клавиатурой и индикатором | открывается, кнопки работают |
| Набор числа, арифметика | 5 + 3 = 8 |
| Регистры: X→П и П→x | запись и чтение, регистр выбирается нажатием под индикатором |
| Запись в регистр завершает набор | 5 → X→П → R1 → 7 даёт **7** (было 57) |
| Режим ПРГ | нажатия пишут коды в память команд |
| Контрольные тесты | 82 из 82, долг 1 из 3 |

## Файлы

- `index.html` — копия рабочего `index.html`; пути к `profiles.js` и `core.js` поправлены на `../../`, потому что страница лежит в подпапке
- `sto-fix.js` — точная копия надстройки, закрывающей третий долг

Ядро `core.js` в архив не копируется: страница берёт его из корня с маркером `?v=12`.

## Что осталось за рамками этапа

- Правка `X→П` внутри самого `core.js` — в тестах долг по-прежнему виден, потому что `tests.html` работает с ядром напрямую, без надстройки
- Пометки `known` у `4F` и `6F` в `tests.html`: коды уже дают R0, но счётчик пишет «долг 1 из 3» вместо «долг 1 из 1»
- Корпус для `pmk52` (Б3-34 и МК-52)
- Точная раскладка клавиш настоящей МК-61: сейчас как у обычного калькулятора
